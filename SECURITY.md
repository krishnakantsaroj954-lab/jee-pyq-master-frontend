# Security Policy

## Supported Versions

Currently, there are no active supported versions of this software, as the repository is essentially a placeholder devoid of application code.

| Version | Supported          |
| ------- | ------------------ |
| N/A     | :white_check_mark: |

## Reporting a Vulnerability

Since this repository contains no application code, it is unlikely to contain a security vulnerability in its current state.

However, if application code is added in the future and you discover a security vulnerability, please report it privately. **Do not create a public issue.**

Please email the project maintainers with details about the vulnerability. We will try to respond as quickly as possible.
